# Microsoft Azure Research

## Brief Overview
Microsoft Azure is Microsoft's cloud computing platform launched in 2010. It provides a comprehensive suite of cloud services, with strong integration with Microsoft's software ecosystem.

## Global Infrastructure
- **Regions:** 60+ regions worldwide
- **Availability Zones:** 60+ availability zones
- **Edge Locations:** 200+ edge locations
- **Global Coverage:** Available in 140+ countries

## Cloud Management Console
- **Azure Portal:** Web-based management interface
- **Azure CLI:** Command-line interface
- **Azure PowerShell:** PowerShell modules
- **Azure Resource Manager:** Infrastructure deployment

## Four Core Services

### 1. Compute - Azure Virtual Machines
Windows and Linux virtual machines with on-demand scaling

### 2. Storage - Azure Blob Storage
Object storage for unstructured data with tiered storage options

### 3. Networking - Azure Virtual Network
Private network connectivity with security features

### 4. Identity - Microsoft Entra ID (Azure AD)
Cloud-based identity and access management service

## Three Advantages
1. **Microsoft Integration:** Seamless with Windows Server, Active Directory, and Microsoft 365
2. **Hybrid Cloud:** Best-in-class hybrid capabilities
3. **Enterprise Focus:** Strong in enterprise deployments

## Typical Enterprise Use Cases
- Microsoft application modernization (.NET, SQL Server)
- Hybrid cloud deployments
- Enterprise application migration
- Windows-based workloads
