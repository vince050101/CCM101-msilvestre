# Laboratory 02: Welcome to the Cloud

## Mission Overview
This activity introduces cloud-based Linux environments and GitHub portfolio management.

## Objectives
- Access KillerCoda Linux environment
- Navigate Linux file system
- Gather system information
- Create GitHub repository
- Document work using Markdown

## Activities Performed
1. Created new user in Linux
2. Gathered system information
3. Built directory structure
4. Created GitHub repository
5. Documented all steps

## Linux Commands Used
- `useradd`, `passwd`, `usermod` - User management
- `lsb_release`, `uname`, `lscpu` - System info
- `mkdir`, `cd`, `pwd` - Directory navigation
- `nano` - Text editing
- `git` - Version control

## Skills Learned
- Linux command line proficiency
- System information gathering
- File organization and management
- GitHub repository creation and maintenance
- Markdown documentation
